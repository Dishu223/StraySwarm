## Formatting Guidelines for Future Entries

When adding new entries to this changelog, please adhere to the following guidelines:

1. **Keep it simple:** Use clear, concise language.
2. **Categorize changes:** Always group items under `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, or `Security`.
3. **Chronological order:** Newest versions go at the top.
4. **Include dates:** Format dates as YYYY-MM-DD.
5. **Reference issues:** If a change fixes a specific bug or resolves an issue, include the issue number (e.g., "Fixed #123").

This changelog is a critical communication tool for the development team and will eventually be used to generate release notes for players.
